# 기어 앤 포션 (Gear & Potion: Automate the Atelier)

2D 그리드 기반 **마도 자동화 공방 + 포션 상점 타이쿤** — Unity 6 (6000.3.11f1) · 2D URP · C# 1인 개발 프로젝트.
Google Drive의 「[상세 기획서] 기어 앤 포션」 GDD v1.0을 바탕으로 만든 **수직 슬라이스(v0.5.0)** 입니다.

뒷방(공방)에서는 투입구 → 분쇄기 → 추출기 → 여과기 → 병입기가 벨트와 마력 배관으로 이어져 돌아가고,
벽 너머 앞가게(매장)에서는 손님이 진열대의 포션을 사 갑니다.

## 실행 방법

1. Unity Hub에서 이 폴더를 열기 (Unity **6000.3.11f1**)
2. 메뉴 **Gear & Potion → Setup Project** 실행 (데이터 에셋·씬·빌드 설정 생성, 다시 실행해도 안전)
3. `Assets/_Project/Scenes/Atelier.unity` 열고 Play
4. 빌드: **Gear & Potion → Build Windows** → `Builds/Windows/GearPotion.exe`

아트·사운드 에셋 없이 동작합니다. 스프라이트는 런타임 SDF로, 효과음은 합성으로 생성됩니다
(실제 32x32 픽셀 아트로 교체할 때는 `Sprites.cs`의 프로퍼티만 바꾸면 됩니다).

## 배관 레이어 (v0.2.0)

- **고체**(재료·분말·포션·슬러지)는 벨트로, **액체 원액**은 마력 배관으로만 이동합니다. 벨트·분배기는 원액을 받지 않습니다.
- 추출기·여과기·증류탑·합성 가마의 출력 칸(▶)에 배관을 놓으면 원액이 배관으로 나갑니다.
- 이어진 배관은 하나의 **네트워크**가 되어, 배관에 닿은 여과기·증류탑·가마·병입기에 차례로(라운드로빈) 공급합니다. 원액을 넣은 설비로는 되돌려 보내지 않습니다.
- 네트워크 용량은 `2 + 배관 칸수/2`, 이동 시간은 길이에 비례합니다. 배관은 원액 색으로 맥동합니다.
- 배관은 벨트 위에 겹쳐 놓을 수 있습니다(교차). 설비끼리 바로 맞닿으면 배관 없이도 직접 넘어갑니다.
- 합성 가마 혼합 모드(클릭): 기본은 **서로 다른 원액끼리**(주 원소가 다른 것)만 짝지어 섞고, 독샘+독샘처럼 같은 원액을 섞으려면 모드를 바꿉니다.
- v0.1 세이브는 불러올 때 원액이 다니던 벨트 구간을 자동으로 배관으로 바꿉니다.

## 과열 · 냉각 (v0.3.0)

- 가동 중인 가공 설비는 열이 쌓입니다 (분쇄 3 · 추출 4 · 여과 3 · 증류 6 · 가마 5 · 병입 2 /s, 화 원소 재료 +2). 기본 방열은 5/s.
- **오버클럭 태엽**(40G, 연구 90RP): 가공 설비를 클릭해 부착 → 처리 속도 150%, 발열 2배. 다시 클릭하면 분리(75% 환불).
- 열이 **100**이 되면 화재: 6초 정지, 안에 있던 재료 소실, 이웃 가공 설비로 열 전파. 70 이상이면 붉게 달아오르며 경고.
- 냉각: **얼음 정령석**(60G, 연구 60RP)을 맞닿게 두면 개당 -6/s, 물 원소 원액이 흐르는 배관이 닿으면 **냉각수 배관**으로 -5/s.

## 세력 납품 계약 (v0.4.0)

- Day 2부터 매일 새벽 의뢰 3건이 들어옵니다(암시장은 Day 3부터). 계약 게시판(**C**)에서 최대 2건까지 수락합니다.
- 공방의 **납품 상자**로 조건에 맞는 포션을 보내면 계약 진행도가 오르고, 다 채우면 보상을 일괄 지급합니다. 조건에 안 맞는 포션은 기존처럼 도매(70%)로 팔립니다.
- 진행 상황은 왼쪽 목표 패널에 `[계약] 치유 B+ 5/14 (D-2)` 형태로 표시되고, 정산서에 계약 보상·실패 건수가 나옵니다.

| 세력 | 의뢰 성격 | 보상 배율 | 첫 성공 혜택 (영구) |
|---|---|---|---|
| 모험가 길드 | B급 이상 중량, 3일 | x1.6 | 얼음 정령의 파편·용암 도마뱀의 독샘 해금, 두 재료 10% 할인 |
| 왕립 마법 학회 | A급(Day 6부터 S급) 이상 소량, 2일 | x2.2 | 얼음 정령석·슬라임 배양조·VIP 쇼케이스 해금 + 60 RP |
| 대륙 상인 연합 | 등급 무관 대량, 4일 | x1.2 | 원재료 15% 할인, 벨트·배관·분배기 건설비 50% |
| 그림자 암시장 | 부작용 포션(C급·탁한 물약), 2일 | x3.0 (완료 시 의심 +20) | 암시장 의심 수치 증가 절반 |

- 성공할 때마다 그 세력 평판 +1(의뢰량·보상 증가), 기한을 넘기면 평판 -1. 의뢰는 날짜·평판으로 정해지므로 이어하기해도 같습니다.

## 청사진 (v0.5.0)

- **B** 또는 하단 **B 청사진** 버튼 → `+ 영역 복사해서 새 청사진` → 공방에서 설비 묶음을 좌클릭 드래그로 감싸면 저장됩니다.
- 영역 안에 완전히 들어오는 설비·배관이 방향·설정(투입 재료, 가격 배율, 분류 조건, 혼합 모드)·오버클럭까지 그대로 담깁니다. 계산대는 제외.
- 저장 직후 커서에 묶음이 붙습니다. **R**(Shift+R 역방향)로 회전, 좌클릭으로 설치(반복 가능), 우클릭/Esc로 종료.
- 설치 가능한 칸의 설비만 골라 비용을 한 번에 지불하고, 막힌 칸·미해금 설비는 건너뜁니다(미리보기에서 빨간색).
- 청사진은 최대 8개, 세이브와 별개 파일(`gearpotion_blueprints.json`)이라 모든 공방에서 공용입니다.
